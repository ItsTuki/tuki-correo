# 📬 Tuki Correo

App de correo para **Windows** y **Android** sobre los servidores Stalwart de mis dominios (@itstuki.cl y otros). Entras con tu dirección y la app encuentra sola el servidor.

- **Cuenta de usuario:** bandeja con carpetas y búsqueda, redactar con adjuntos (con porcentaje de subida), archivos en la nube y tu espacio usado.
- **Cuenta de administrador:** además, un panel para crear cuentas, asignar cuotas, ver el almacenamiento y ajustar los límites de tamaño.
- **Se actualiza sola** y te avisa qué se mejoró o arregló.

## ⬇ Descargar

Página del proyecto: **https://correo.itstuki.cl**

En [Releases](https://github.com/ItsTuki/tuki-correo/releases/latest) está la última versión:

| Archivo | Para |
|---|---|
| `TukiCorreo-X.Y.Z-instalador.exe` | Windows, se instala y se actualiza solo |
| `TukiCorreo-X.Y.Z-portable.exe` | Windows, sin instalar (avisa cuando hay versión nueva) |
| `TukiCorreo-X.Y.Z.apk` | Android 7 o superior |

En Android, la primera vez el teléfono pide permitir la instalación desde el navegador o el administrador de archivos.

## Sobre este repositorio

Aquí solo se publican las versiones; la app las revisa para actualizarse. El código está en un repositorio privado y cada versión se compila y sube con GitHub Actions.
